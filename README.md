# صلاتي — My Prayer (iOS)

تطبيق مستقل بلغة SwiftUI لتنبيهات مواقيت الصلاة الخمس فقط. يتضمن حساب المواقيت، اختيار المدينة أو GPS، طريقة الحساب الجعفرية، تصحيح الدقائق، العد التنازلي، الإشعارات المخصصة وجدول 30 يومًا.

## البناء

افتح تبويب **Actions** ثم **Build iOS IPA (unsigned)**. الملف الناتج غير موقّع، ويحتاج توقيعًا صالحًا قبل التثبيت على iPhone. يمكن أيضًا فتح المشروع بعد تشغيل `xcodegen generate` على macOS.

يستخدم المشروع مكتبة [Adhan Swift](https://github.com/batoulapps/adhan-swift) مرخّصة MIT. طريقة الحساب التقريبية ليست بديلاً عن التحقق من تقويم المسجد أو المرجعية. iOS لا يضمن تشغيل أذان كامل بالخلفية بواسطة إشعار عادي؛ الأصوات القصيرة فقط مع مراعاة وضع الصامت والتركيز.
